# ✨ TaskFlow — JavaScript To-Do List

A simple and interactive **To-Do List web application** built with **HTML, CSS and Vanilla JavaScript**.


## 🌐 Live Demo

👉 **[View Live Demo](https://rashiuwu.github.io/taskflow-todo/)**

## 🚀 Features

* ➕ Add new tasks
* ✏️ Edit tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 🔍 Filter: All, Active & Completed
* 💾 Save tasks using `localStorage`
* 🔄 Data remains after browser refresh
* ⚡ Dynamic DOM manipulation
* 🎯 Event delegation

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* DOM API
* LocalStorage

```bash

```
